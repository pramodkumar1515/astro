# Acharya Abhishek Mishra — Divya Akash

Vercel-ready Next.js + React Three Fiber website.

## Run
```bash
npm install
npm run build
npm run dev
```

Copy `.env.example` to `.env.local` and add only VERIFIED professional contact details.

## Research status
The requested authenticated Facebook research could not be performed in this execution environment because the user's logged-in Facebook browser session is not exposed here. The build therefore deliberately publishes no unverified services, contact numbers, events, biography, photos, or external social identities. See `/research`.
